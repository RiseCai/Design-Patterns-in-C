API Integration

The Recording FSM provides the following API functions that are called by the System Coordinator:

  • recording_fsm_init() – Initialize the FSM
  • recording_fsm_dispatch_event() – Dispatch an event to the current state
  • recording_fsm_get_state() – Get current state of the FSM
  • recording_fsm_set_error() – Set error state
  • recording_fsm_get_error_msg() – Get error message

These API calls are annotated on the diagram to show how the System Coordinator interacts with this subsystem.
