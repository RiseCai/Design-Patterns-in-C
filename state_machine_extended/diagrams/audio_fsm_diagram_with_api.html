API Integration

The Audio FSM provides the following API functions that are called by the System Coordinator:

  • audio_fsm_init() – Initialize the FSM
  • audio_fsm_process() – Dispatch an event to the current state
  • audio_fsm_play() – Start audio playback
  • audio_fsm_pause() – Pause playback
  • audio_fsm_set_volume() – Adjust volume level
  • audio_fsm_set_eq() – Change equalizer preset
  • audio_fsm_toggle_anc() – Toggle noise cancellation

These API calls are annotated on the diagram to show how the System Coordinator interacts with this subsystem.
