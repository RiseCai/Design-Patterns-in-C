Sequence Description

This sequence diagram illustrates four main scenarios:

  1. Normal Recording Flow: User starts recording, system transitions through IDLE → RECORDING → UPLOADING → IDLE states.
  2. Error Recovery Flow: Error occurs during recording, system enters ERROR state, then resets to IDLE.
  3. Power Management Flow: Low battery warning triggers SLEEP state, then power off leads to SHUTDOWN.
  4. External Device Control Command Flow: External device sends commands via Bluetooth/4G, which are processed by an external command processor and dispatched to the system coordinator, demonstrating three modes: Direct Event, Callback with Queue, and Hybrid (Callback + Queue).

The diagram shows interactions between:

  • User: Initiates actions via test program
  • Test Program: Calls system coordinator API functions
  • System Coordinator: Main coordinator FSM
  • Recording FSM: Handles audio recording operations
  • Power FSM: Manages power states
  • Comm FSM: Handles communication and upload
  • External Device: Sends control commands via wireless
  • External Command Processor: Parses and forwards commands to system coordinator

This coordinated sequence ensures all subsystems are properly initialized and ready before recording begins, and demonstrates how external device control commands can be integrated into the system.
