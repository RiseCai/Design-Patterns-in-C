API Integration

The Communication FSM provides the following API functions that are called by the System Coordinator:

  • comm_fsm_init() – Initialize the FSM
  • comm_fsm_dispatch_event() – Dispatch an event to the current state
  • comm_fsm_is_connected() – Check connection status
  • comm_fsm_start_transfer() – Start data transfer
  • comm_fsm_set_error() – Set error state

These API calls are annotated on the diagram to show how the System Coordinator interacts with this subsystem.
