System Coordinator FSM

The top‑level state machine that coordinates all subsystems. It manages system‑wide states (INIT, IDLE, RECORDING, UPLOADING, ERROR, SLEEP, SHUTDOWN) and dispatches events to the appropriate subsystems.

Simulation Instructions

Click on an event button to trigger a state transition. The system follows these rules:

  • SYS_INIT: Automatically transitions to SYS_IDLE after initialization.
  • SYS_IDLE: Can transition to SYS_RECORDING (REC_START), SYS_SHUTDOWN (POWER_OFF), or SYS_ERROR (ERROR).
  • SYS_RECORDING: Can transition to SYS_UPLOADING (REC_STOP) or SYS_ERROR (ERROR).
  • SYS_UPLOADING: Can transition to SYS_IDLE (UPLOAD_COMPLETE) or SYS_ERROR (ERROR).
  • SYS_ERROR: Can transition to SYS_INIT (RESET) or SYS_SHUTDOWN (POWER_OFF).
  • SYS_SLEEP: Can transition to SYS_IDLE (POWER_ON).

Subsystems Overview

The system coordinator manages four subsystems, each with its own state machine.

🔋 Power FSM

Scenario: Power Management

Type: Mealy / Moore

Key Features: Battery monitoring, charging states, low‑power sleep.

  • States: OFF, ON, CHARGING, LOW_BATTERY
  • Events: power_on, power_off, charge_start, charge_complete, battery_low
