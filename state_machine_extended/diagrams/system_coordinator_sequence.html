Description

This sequence diagram illustrates three main scenarios:

  1. Normal Recording Flow: User starts recording, system transitions through IDLE → RECORDING → UPLOADING → IDLE states.
  2. Error Recovery Flow: Error occurs during recording, system enters ERROR state, then resets to IDLE.
  3. Power Management Flow: Low battery warning triggers SLEEP state, then power off leads to SHUTDOWN.

The diagram shows interactions between:

  • User: Initiates actions via test program
  • Test Program: Calls system coordinator API functions
  • System Coordinator: Main coordinator FSM
  • Recording FSM: Handles audio recording operations
  • Power FSM: Manages power states
  • Comm FSM: Handles communication and upload
