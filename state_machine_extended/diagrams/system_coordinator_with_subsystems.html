System Coordinator FSM

The top‑level state machine that coordinates all subsystems. It manages system‑wide states (INIT, IDLE, RECORDING, UPLOADING, ERROR, SLEEP, SHUTDOWN) and dispatches events to the appropriate subsystems.

Subsystem Mapping Table

Mapping between System Coordinator states and active subsystems.

System Coordinator State Active Subsystems Subsystem States Description
SYS_INIT All INIT, IDLE All subsystems are initialized.
SYS_IDLE Power, Communication, Audio IDLE, CONNECTED, IDLE System ready, waiting for user input.
SYS_RECORDING Recording, Audio, Power RECORDING, RECORDING, ON Recording audio, audio FSM active, power ON.
SYS_UPLOADING Communication, Recording TRANSFERRING, UPLOADING Uploading recorded data via communication.
SYS_ERROR All ERROR (or previous) Error state, subsystems may be in error or halted.
SYS_SLEEP Power, Communication SLEEP, DISCONNECTED Low‑power sleep, communication disconnected.
SYS_SHUTDOWN All OFF, DISCONNECTED, IDLE System shutting down, subsystems turned off.

Subsystem Dependencies

  • Communication FSM: Required for data upload and Bluetooth connectivity.
  • Power FSM: Manages battery and power states, influences system‑wide sleep/shutdown.
  • Audio FSM: Handles audio playback and recording; active during RECORDING state.
  • Recording FSM: Manages recording lifecycle; coordinates with Audio FSM.
