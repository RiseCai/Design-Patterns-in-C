API Integration

The Power FSM provides the following API functions that are called by the System Coordinator:

  • power_fsm_init() – Initialize the FSM
  • power_fsm_handle_event() – Dispatch an event to the current state
  • power_fsm_get_battery_level() – Get current battery percentage
  • power_fsm_is_charging() – Check charging status
  • power_fsm_enter_low_power() – Enter low‑power mode
  • power_fsm_shutdown() – Graceful shutdown

These API calls are annotated on the diagram to show how the System Coordinator interacts with this subsystem.
