State Details

  • SYS_INIT: Initialization state. Automatically transitions to IDLE after subsystems are initialized.
  • SYS_IDLE: Main operational state. System is ready for user interaction.
  • SYS_RECORDING: Recording audio data. Activates recording_fsm and audio_fsm.
  • SYS_UPLOADING: Uploading recorded data to cloud. Uses network connection.
  • SYS_ERROR: Error handling state. Contains error_code and error_msg for diagnostics.
  • SYS_SLEEP: Low-power sleep mode. Subsystems are in low-power state.
  • SYS_SHUTDOWN: System shutdown. Final state before power off.

API Functions

  • system_coordinator_init(struct system_coordinator *sys): Initialize the system coordinator.
