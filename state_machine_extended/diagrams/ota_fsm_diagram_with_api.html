API Integration

The OTA FSM provides the following API functions that are called by the System Coordinator:

  • ota_fsm_init() – Initialize the FSM
  • ota_fsm_dispatch_event() – Dispatch an event to the current state
  • ota_fsm_get_state() – Get current state of the FSM
  • ota_fsm_get_state_name() – Get human‑readable state name
  • ota_fsm_set_package_url() – Set the OTA package URL
  • ota_fsm_add_module() – Add a module to be updated
  • ota_fsm_get_overall_progress() – Get overall progress percentage
  • ota_fsm_set_error() – Set error state with custom message

These API calls are annotated on the diagram to show how the System Coordinator interacts with this subsystem.
