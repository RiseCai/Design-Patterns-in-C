System Coordinator FSM

The top‑level state machine that coordinates all subsystems. It manages system‑wide states (INIT, IDLE, RECORDING, UPLOADING, ERROR, SLEEP, SHUTDOWN) and dispatches events to the appropriate subsystems.

Subsystems Overview

The system coordinator manages four subsystems, each with its own state machine.

🔋 Power FSM

Scenario: Power Management

Type: Mealy / Moore

Key Features: Battery monitoring, charging states, low‑power sleep.

  • States: OFF, ON, CHARGING, LOW_BATTERY
  • Events: power_on, power_off, charge_start, charge_complete, battery_low
  • API: power_fsm_dispatch_event()
  • Code: power_fsm.c / power_fsm.h

State Mapping Table

Mapping between system coordinator states and subsystem states.

System Coordinator State Subsystem Subsystem State Description
SYS_IDLE Power FSM ON System powered on, battery normal
SYS_IDLE Audio FSM IDLE Audio playback stopped, ready

SYS_RECORDING Audio FSM RECORDING Audio recording active

SYS_UPLOADING Communication FSM TRANSFERRING Uploading data to cloud
SYS_ERROR All subsystems ERROR Error state propagated
