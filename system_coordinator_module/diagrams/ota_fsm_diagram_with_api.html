State Details

  • OTA_IDLE: Initial state. OTA subsystem is idle, waiting for start.
  • OTA_CHECKING: Checking for available updates.
  • OTA_DOWNLOADING: Downloading the update package.
  • OTA_VALIDATING: Validating the downloaded package.
  • OTA_PREPARING: Preparing the system for installation.
  • OTA_INSTALLING: Installing the update.
  • OTA_REBOOTING: Rebooting the system after installation.
  • OTA_ROLLBACK: Rolling back to previous version (error state).
  • OTA_COMPLETE: OTA completed successfully.
  • OTA_ERROR: Error state, contains error information.

API Functions

  • ota_fsm_init(): Initialize the OTA FSM.
  • ota_fsm_dispatch_event(enum ota_event event): Dispatch an event to the state machine.
  • ota_fsm_get_state(): Get current state.
  • ota_fsm_get_state_name(): Get state name as string.
  • ota_fsm_set_package_url(const char *url): Set the package download URL.
  • ota_fsm_add_module(const char *module_name): Add a module to be updated.
  • ota_fsm_get_overall_progress(): Get overall progress percentage.
  • ota_fsm_set_error(int code, const char *msg): Set error information.
