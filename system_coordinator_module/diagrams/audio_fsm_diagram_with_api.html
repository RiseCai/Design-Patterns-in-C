State Details

  • AUDIO_OFF: Initial state. Audio subsystem is powered off.
  • AUDIO_IDLE: Audio subsystem is initialized and ready for playback or recording.
  • AUDIO_PLAYING: Audio playback is active.
  • AUDIO_PAUSED: Playback is paused.
  • AUDIO_RECORDING: Audio recording is active.
  • AUDIO_ERROR: Error state. Contains error information for diagnostics.

API Functions

  • audio_fsm_init(): Initialize the audio FSM.
  • audio_fsm_dispatch_event(enum audio_event event): Dispatch an event to the state machine.
  • audio_fsm_get_state(): Get current state.
  • audio_fsm_set_error(int code, const char *msg): Set error information in ERROR state.
  • audio_fsm_get_error_msg(): Retrieve error message.
