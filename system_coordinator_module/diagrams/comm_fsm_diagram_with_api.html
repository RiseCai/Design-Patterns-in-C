State Details

  • COMM_IDLE: Initial state. Communication subsystem is idle, ready to connect.
  • COMM_CONNECTING: Actively attempting to establish a connection.
  • COMM_CONNECTED: Connection established, ready for data transfer.
  • COMM_TRANSFERRING: Actively transferring data.
  • COMM_DISCONNECTING: Gracefully disconnecting.
  • COMM_ERROR: Error state. Contains error information for diagnostics.

API Functions

  • comm_fsm_init(): Initialize the communication FSM.
  • comm_fsm_dispatch_event(enum comm_event event): Dispatch an event to the state machine.
  • comm_fsm_is_connected(): Check if the communication is connected.
  • comm_fsm_start_transfer(): Start data transfer.
  • comm_fsm_set_error(int code, const char *msg): Set error information in ERROR state.
  • comm_fsm_get_error_msg(): Retrieve error message.
