State Details

  • REC_IDLE: Initial state. Recording FSM is idle, ready to start recording.
  • REC_WAIT_SYNC: Waiting for synchronization with audio subsystem before actual recording starts.
  • REC_RECORDING: Actively recording audio data. Audio buffers are being filled.
  • REC_PAUSED: Recording paused temporarily. Buffers are held but not written.
  • REC_STOPPING: Recording stopped, saving data to storage (e.g., file or memory).
  • REC_ERROR: Error state. Contains error code and message for diagnostics.

API Functions

  • recording_fsm_init(struct recording_fsm *fsm): Initialize the recording FSM.
  • recording_fsm_dispatch_event(struct recording_fsm *fsm, enum recording_event event, void *data): Dispatch an event to the state machine.
  • recording_fsm_get_state(struct recording_fsm *fsm): Get current state.
  • recording_fsm_set_error(struct recording_fsm *fsm, int code, const char *msg): Set error information in ERROR state.
  • recording_fsm_get_error_code(struct recording_fsm *fsm): Retrieve error code.
  • recording_fsm_get_error_msg(struct recording_fsm *fsm): Retrieve error message.
