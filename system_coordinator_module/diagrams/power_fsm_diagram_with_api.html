State Details

  • POWER_OFF: Initial state. Power subsystem is off.
  • POWER_ON: Power is on, system operational.
  • POWER_LOW_BATTERY: Low battery condition (error state).
  • POWER_CHARGING: Battery is charging.
  • POWER_SLEEP: Low-power sleep mode.

API Functions

  • power_fsm_init(): Initialize the power FSM.
  • power_fsm_dispatch_event(enum power_event event): Dispatch an event to the state machine.
  • power_fsm_get_state(): Get current state.
  • power_fsm_get_state_name(): Get state name as string.
