State Details

  • SYS_INIT: Initialization state. Automatically transitions to IDLE after subsystems are initialized. May transition to OTA if a pending firmware update is detected.
  • SYS_IDLE: Main operational state. System is ready for user interaction. Monitors battery, network, and user commands.
  • SYS_RECORDING: Recording audio data. Activates recording_fsm and audio_fsm.
  • SYS_RECORDING_AND_UPLOADING: Simultaneous recording and streaming. Both recording_fsm, audio_fsm, and comm_fsm are active.
  • SYS_UPLOADING: Uploading recorded data to cloud. Uses network connection (comm_fsm).
  • SYS_OTA: Over‑the‑air firmware update. Activates ota_fsm.
  • SYS_ERROR: Error handling state. Contains error_code and error_msg for diagnostics. Can recover via reset or shutdown.
  • SYS_SLEEP: Low‑power sleep mode. Subsystems are in low‑power state.
  • SYS_SHUTDOWN: System shutdown. Final state before power off.
  • SYS_RESET: Reset state. Resets subsystems and automatically transitions back to INIT.

API Functions

  • system_coordinator_init(struct system_coordinator *sys): Initialize the system coordinator.
  • system_coordinator_dispatch_event(struct system_coordinator *sys, enum system_event event, void *data): Dispatch an event to the state machine.
  • system_coordinator_get_state(struct system_coordinator *sys): Get current state.
  • system_coordinator_set_error(struct system_coordinator *sys, int code, const char *msg): Set error information in ERROR state.
  • system_coordinator_get_error_code(struct system_coordinator *sys): Retrieve error code.
  • system_coordinator_get_error_msg(struct system_coordinator *sys): Retrieve error message.
