Protocol Overview

The EFSM protocol is not a visual state machine but a set of rules for subsystem interaction. It includes:

  • Events: System‑wide events (e.g., SYS_EVT_RECORD_START, SYS_EVT_UPLOAD_COMPLETE).
  • Conditions: Guards that determine whether a transition can be taken.
  • Actions: Functions executed during transitions (e.g., start recording, send data).
  • Extended Variables: Context variables (e.g., battery level, connection status).

API Functions

  • efsm_protocol_init(): Initialize the EFSM protocol.
  • efsm_protocol_register_event_handler(enum sys_event event, event_handler_t handler): Register a handler for a system event.
  • efsm_protocol_dispatch_event(enum sys_event event, void *data): Dispatch a system event to all registered handlers.
  • efsm_protocol_set_condition(const char *condition_name, bool (*cond_func)(void *)): Set a condition function.
  • efsm_protocol_add_action(const char *action_name, void (*action_func)(void *)): Add an action function.
  • efsm_protocol_get_variable(const char *var_name): Get an extended variable value.
  • efsm_protocol_set_variable(const char *var_name, int value): Set an extended variable.
